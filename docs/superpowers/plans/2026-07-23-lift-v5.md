# Lift v5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Commanded footswing height (obs 227, teacher-only), knee-deweighted pose, upright deadzone, w_air 1.0 — then the probe gate proves the walls are down before any GPU run.

**Architecture:** Task 1 = c-command plumbing (env.py + tests). Task 2 = posture changes + w_air (env.py + tests) and the probe c-override. Task 3 = train.py threading + fingerprint + full suite + PROBE RUN (the gate). Spec: `docs/superpowers/specs/2026-07-23-lift-v5-design.md` — read it first; it holds the design rationale and exact semantics.

**Tech Stack:** JAX/Brax MJX; tests `JAX_PLATFORMS=cpu` from `sim/nova_mjx/`, foreground, 600000 ms, ONE file per call.

## Global Constraints

- `FOOTSWING_MIN = 0.015`, `FOOTSWING_MAX = 0.06` module consts; env kwarg `footswing_max=FOOTSWING_MAX`; `--footswing-max` default imports the const.
- `c` lives in `info["cmd_c"]`; resampled with `cmd` (same `step % 250` site); heightmap=True → obs gains `c` as the LAST dim (after the heightmap block), obs 226→227; heightmap=False → obs unchanged (105) and `c` FIXED at `BLIND_FOOTSWING = 0.05` (const), never resampled.
- Clearance cost target = `info["cmd_c"]`: `jp.maximum(cmd_c - foot_h, 0.0) * jp.sqrt(foot_xy_speed)`; weight `-self._w_clearance` unchanged. `--foot-target-z` and `self._foot_target_z` REMOVED (grep all uses incl. tests; the v3 tests that swept it get updated to sweep `cmd_c` via info override).
- Pose: per-joint weights hfe **1.0** / kfe **0.1** inside the existing contact gate; weight 0.5 unchanged.
- Upright: `UPRIGHT_DEADZONE = 0.067` const (sin²15°); `upright = jp.maximum(0.0, up_x²+up_y² − UPRIGHT_DEADZONE)` replacing the `(up − ẑ)²` form; weight line unchanged.
- `w_air = move_gate * 1.0 * air_rew` (was 0.5) + comment citing reference range 1.0-2.0.
- NO new positive terms beyond the w_air weight change. No touch: w_climb/beta/PBRS, carry/air windows, clip, stage schedule, terrain.
- Obs-size assertions and heightmap tests: teacher envs 227 everywhere they said 226; blind stays 105.
- Commits per task: `sim/env: …` ×2, `sim/train: …`.
