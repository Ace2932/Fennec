# PCB Modifications

Notes on bypasses, cuts, and re-uses of the NovaSM3 v5.2b PCB.

## Will contain
- Retained: battery input, reverse-polarity protection, 12A buck #1 (6.8V),
  power switch, voltmeter, fuse, Arduino Nano aux slot
- Bypassed: 12× PWM servo headers (Feetech bus replaces)
- Modifications: jumper wires for split power rails, LC filter for L2 12V tap
- Schematic diffs vs upstream Nova v5.2b
- Photos of as-built rework
